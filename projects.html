Project 03

Web-Controlled ESP32 Cart

Embedded Systems Team Project

View Details in GitHub ↗

We built a battery-powered cart that users can drive from a phone or computer. An ESP32-C6 creates its own Wi-Fi network and hosts the control page, so the cart does not need an app or external router.

How It Works

  1. The user connects to the cart's Wi-Fi and opens its control page in a browser.
  2. Direction and power buttons send HTTP commands to the main ESP32-C6.
  3. The main controller drives both motors, reads the IMU, and sends status data over UART to the second ESP32-C6.
  4. The second controller updates the two OLED displays as turn signals and brake lights.

Control & Motion

  • TB6612FNG driver controls two 12 V DC motors.
  • ICM-20948 acceleration data is filtered to estimate cart speed.
  • PWM startup and shutdown chimes

Communication & Display

  • HTTP requests carry browser commands.
  • UART transfers commands and speed data between both controllers.
  • Two I2C-addressed SSD1306 OLED displays show driving signals.
  • U8g2 display library

Build Process

We first scoped a GPS follow-me concept into a web-controlled prototype that could be completed and tested reliably. After integrating the frame, motors, controllers, and displays, we strengthened the wheel adapters with resin, corrected motor direction in software, and moved UART to separate serial pins to resolve a hardware conflict.
